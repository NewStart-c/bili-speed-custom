# 路线图

当前版本：**2.0.0**（2026-11-02）。阶段一已完成，以下为后续规划。

## 阶段一：稳定性 + 设置/发布基础（已发布 v2.0.0）

- [x] TypeScript + esbuild 工程化，`dist/` 构建产物
- [x] 播放器精准定位与 `bwp-video` 兼容
- [x] 目标倍速状态机：SPA、切集、切 P、换清晰度后恢复
- [x] 原生倍速菜单选择持久化
- [x] 菜单关闭回归加固（移除持久内联 `display:none`）
- [x] 快捷键改用 `e.code`，排除 contenteditable
- [x] 输入框预填、逗号小数、非法值提示、步进、1x、Esc
- [x] Popup + Options（预设管理、默认倍速、步长、导入/导出/恢复默认）
- [x] 设置 schema 与旧键迁移
- [x] Vitest 单元测试、Playwright E2E、GitHub Actions CI
- [x] 发布 zip 打包、README、CHANGELOG、隐私说明

## 阶段二：个性化与快捷操作

- [ ] 分层记忆：全局 → 视频 → 分 P → 合集/番剧季 → UP → 分区，逐级 fallback
- [ ] 记忆数据 LRU 上限与清理
- [ ] 长按临时倍速（松开恢复）
- [ ] Ctrl/Alt + 滚轮或快捷键按步长微调
- [ ] 全屏 OSD 倍速提示
- [ ] 平滑倍速过渡与“保持音调”开关
- [ ] 跨标签页同步；设置可选 `chrome.storage.sync`
- [ ] 支持 `/list/*`、`/festival/*`、`/cheese/play/*`
- [ ] 快捷键自定义与冲突检测

## 阶段三：高级玩法与生态

- [ ] 智能倍速规则：按分区、时长、UP、标题关键词匹配
- [ ] 学习模式：A-B 循环、片段复听、时间点笔记
- [ ] 本地速度统计：累计观看时长、估算节省时间（默认关闭）
- [ ] 多语言（zh_CN / en）
- [ ] Firefox 兼容评估
- [ ] Chrome Web Store / Edge Add-ons 发布与自动发布流水线

## 实验性创意（先验证需求）

- 速度时间线：在进度条上标记调过速的位置
- 按章节/分 P 调速：课程不同章节使用不同倍速
- 本地速度画像：根据本地历史建议该 UP/分区的常用倍速，不联网
- 配置分享：导出/导入课程倍速配置包
- 画中画/小窗 OSD
- 无障碍播报与完整键盘导航

## 非目标

- 不做云端账号体系或上传观看记录
- 不替代 Bilibili-Evolved 等大型增强脚本，保持轻量与原生菜单优先
- 不追求与原生播放器冲突的全局鼠标手势

欢迎通过 Issue 讨论优先级。
